# Valley Camcorder · Unity

Unity Hub에서 이 `unity` 폴더를 추가하고 **Unity 6000.6.9f1**로 엽니다. Project 창의 **Assets → Valley → Scenes → HwayangValley**를 열고 **Play**를 누릅니다. 처음 열 때는 URP와 지형·시설 메시를 가져옵니다.

| 키 | 동작 |
| --- | --- |
| 첫 왼쪽 클릭, 마우스 | 화면에 커서를 고정하고 시점 이동 |
| WASD, Shift, Ctrl, Space | 걷기, 달리기, 쪼그리기, 점프 |
| Z | 육지에서 엎드리기 전환. 깊은 물에서는 잠수 또는 수면 복귀 |
| 잠수 중 마우스와 WASD, Space | 바라보는 높이에 맞춰 헤엄치기, 빠르게 수면으로 올라오기 |
| 1 / 2 / 3 | 라이플 / 권총 / 기관단총 꺼내기 |
| 왼쪽 클릭 또는 길게 누르기 | 미니카 한 대 발사 또는 연속 발사 |
| 오른쪽 클릭 | 정조준 켜기·끄기 |
| R | 라이플에 한 대씩 장전. 권총과 기관단총은 카트리지 교체 |
| 더플백이나 연습장 상자 옆에서 R 길게 누르기 | 2.4초 동안 재보급. 라이플 미니카 12대 또는 카트리지 2개 |
| C, M | 장비 검사, 권총 모터 전환 |
| H, T | 물건 집기·내려놓기, 가방에서 장비 꺼내기·넣기, 손에 든 물건 던지기 |
| E | 문·접수창 여닫기, 밸브·전등·수도·냉장고 조작, 앉기·일어나기 |
| F | 육지에서 연습장으로 이동하거나 탐방 위치로 복귀 |
| Esc, 왼쪽 클릭 | 일시정지, 재개 |

권총은 카트리지를 옆으로 빼고, 기관단총은 하단으로 뺍니다. 미니카가 남은 카트리지는 보관하며, 빈 카트리지는 바닥에 떨어집니다. 빈 카트리지와 떨어진 미니카는 30초 후 사라집니다. 라이플을 장전하다 클릭하면 이미 넣은 미니카를 유지한 채 옆문을 닫습니다. 오른쪽 클릭이면 옆문을 닫은 뒤 정조준으로 돌아갑니다.

장비 검사 중에는 라이플의 옆문을 열어 내부를 보고, 권총과 기관단총은 카트리지를 분리해 본체의 모터를 시험합니다. 기관단총의 분리된 카트리지 안쪽 나선 트랙은 모터가 돌아가는 동안 멈춰 있습니다.

레인지 손잡이를 바라보고 E를 누르는 동안 점화음과 스파크가 반복됩니다. 가스관 밸브가 열려 있으면 해당 버너에 불이 붙으며, 점화 직후 E를 떼면 불이 꺼질 수 있습니다. 문과 접수창은 E를 잠시 누르고 있으면 열리거나 닫힙니다.

## 편집과 내보내기

- Unity에서 씬의 지형, 숲, 도로와 시설, 상호작용 개체, 카메라를 편집합니다. 씬의 이동 가능 영역은 기존 지도 외곽선과 도로 차단점에서 가져옵니다. 원경에는 계곡 양쪽의 능선과 물길을 이어 붙였습니다.
- [Blender 원본](../blender/valley-assets.blend)에는 계곡의 암반과 건축 재질, 숙소 시설, 소나타, 야영 식기, 손 리그가 있습니다. 손 모델은 다음 명령으로 다시 내보냅니다. 다른 모델도 `-- --collection "컬렉션 이름"`을 붙여 FBX로 가져올 수 있습니다.

```powershell
blender --background blender/valley-assets.blend --python-exit-code 1 --python blender/export-unity.py
```

- 재현 기준이 되는 웹 지도와 Blender 내보내기 파일을 갱신한 다음, 저장소 루트에서 아래 명령으로 Unity 데이터 묶음을 다시 생성합니다. Unity 메뉴 **Valley → Rebuild Imported Valley Scene**은 해당 데이터로 가져오기 씬을 재생성합니다. 씬에서 직접 편집할 때는 다른 이름의 씬에 저장해 편집본을 보관합니다.

```powershell
npm --prefix tools/unity install
npm --prefix tools/unity run export
```

- 장비 포즈만 갱신할 때는 `node tools/unity/gear-export.cjs`를 사용합니다. 설비 연결과 지면별 발소리 분류만 갱신할 때는 `node tools/unity/export.cjs --interactions`를 사용합니다. `npm --prefix tools/unity run sounds`는 웹판의 Web Audio 합성 효과음을 Unity 오디오로 변환합니다. Playwright Chromium을 설치하거나 `VALLEY_CHROMIUM`에 설치된 Chromium 실행 파일을 지정할 수 있습니다.
- Windows 빌드는 Unity의 **File → Build Profiles**에서 활성 씬을 포함해 빌드합니다. 배치 빌드의 진입점은 `ValleyCamcorder.Editor.ValleySceneBuilder.BuildWindows`입니다.

2001년 8월 18일과 26일 촬영의 숲 경계, 암반 층리, 자갈과 녹색 수면을 조명과 재질의 기준으로 삼았습니다. 예전 사진을 참고해 만든 계곡 숙소와 세단 메시도 가져옵니다. 걸음과 호흡은 기존 게임에 사용한 사용자 녹음 구간을 Unity 오디오 클립으로 가져옵니다.

## 웹판과 Unity판 대조

| 영역 | Unity 동작 |
| --- | --- |
| 장비 | 세 장비의 장착, 사격, 장전, 검사, 모터, 정조준과 원본 합성 효과음 |
| 물과 이동 | 깊은 물 자동 수영, Z 잠수, 수중 잔여 호흡과 피해, 되감기와 리스폰, 지면과 계단 재질별 녹음 |
| 시설 | 문·접수창, 냉장고, 전등, 수도, 두 버너, 가스관 밸브, 로비 CCTV, 앉기와 물건 취급 |
| 손상 | 유리와 세라믹 파편, 파손된 변기·세면대 배관, 차량 패널과 타이어 손상, 가스 폭발과 목재 붕괴, 텐트와 파라솔 천 변형 |
| 연습장 | 원판 여덟 개, 완주 시간, 종이 상자 개폐와 재보급 녹음 |

천의 찢김과 지지대 붕괴는 Unity 메시 변형으로 재현합니다. 웹판의 천 바람 애니메이션, 전체 피격 연출과 디버그 전신 캐릭터 데모에는 후속 이식이 필요합니다.
